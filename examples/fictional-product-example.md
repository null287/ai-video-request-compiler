# 虚构示例：15 秒产品演示视频

> 本示例中的产品、人物、台词和画面均为虚构，只用于展示填写方式。

## 原始需求简报

- 产品：虚构的时间管理 App「TempoNote」
- 用途：社交媒体竖屏广告
- 数量：先验证 1 条
- 时长：15 秒
- 画幅：9:16
- 语言：中文
- 台词：`把今天最重要的一件事，留给真正重要的事。`
- 参考素材：一段只用于参考“手机从桌面被拿起”的动作视频
- 不继承：原人物、原背景、原字幕、原 Logo、原音乐

## 编译后的执行稿摘要

### 0-3 秒

- 画面：桌面上只有一部手机和一张便签，手机屏幕朝上。
- 动作：R1 从画面右侧伸手拿起手机。
- 镜头：固定中近景，轻微推进。
- 台词：无。
- UI：不出现。

### 3-8 秒

- 画面：手机停在胸口高度，屏幕朝向镜头但不遮挡人物脸部。
- 动作：R1 点击 TempoNote 中的“今日重点”入口。
- 镜头：切至手机和手部的近景。
- 台词：无。
- UI：只展示已经提供的虚构 UI 素材；不得新增按钮或数字。

### 8-13 秒

- 画面：R1 放下手机，回到桌面前开始书写。
- 镜头：回到中近景，动作连贯。
- 台词：由 R1 逐字说出：`把今天最重要的一件事，留给真正重要的事。`
- UI：不出现。

### 13-15 秒

- 画面：虚构产品名和 CTA 出现在纯色结尾卡。
- 台词：无。
- 验收：台词完整；手机不漂浮、不穿手；结尾卡无真实品牌和未经确认的功能承诺。

## 这个例子体现的规则

1. 参考视频只承担动作参考，不自动带入原人物和品牌。
2. 台词单独锁定，不让 AI 顺手润色。
3. 手机 UI 被绑定到具体时间段和设备状态。
4. 15 秒内的动作、口播和收尾被拆成可检查的时间轴。
5. 先做 1 条样片验证，再决定是否扩展数量。
