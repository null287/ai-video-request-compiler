# 审核、成本与交付门禁

这份文件描述一种通用的生产控制方法。具体预算、模型价格、审批人和时间点必须由每个组织自行填写，不应从别的项目复制。

## 1. 最小验证原则

一个批次不要在方向未确认时直接批量生成。建议按以下顺序：

```text
需求初审
→ 执行稿确认
→ 生成 1 条最小验证样片
→ 记录审核结论
→ 通过后扩量
→ 整批验收
→ 交付归档
```

等待审核期间可以处理其他已授权任务，但不能把“尚未明确通过”当成批量生成许可。

## 2. 成本控制表

| --- | ---: | ---: | ---: | ---: | ---: | --- |
| B-001 |  |  |  |  |  | 待审核 |

成本检查至少确认：

- 预算或日配额的来源、单位和适用范围；
- 模型、分辨率、时长和重试是否计费；
- 失败任务是否收费；
- 扩量前是否有明确审核结论；
- 超出预算时谁能批准例外；
- 成本记录是否能回溯到批次，而不是只看账户总额。

## 3. 三道门禁

### 门禁 A：需求可执行

未满足以下条件时，只能输出待确认清单：

- 时长、数量、画幅和语言明确；
- 台词、产品事实和 UI 文字已锁定；
- 参考素材的继承/排除边界明确；
- 人物、动作、镜头和场景不存在明显冲突；
- 预算或配额负责人已确认。

### 门禁 B：样片可扩量

样片至少检查：

- 人物外观与服装连续性；
- 手部、道具、设备之间的物理关系；
- 动作顺序、镜头衔接和时间轴；
- 口播、口型、字幕和台词完整性；
- 产品 UI、CTA、ending 与需求一致；
- 参考素材没有发生越界继承。

只有指定审核人明确回复“可继续/通过”或组织规定的等价状态，才进入扩量。

### 门禁 C：整批可交付

- 文件数量与命名一致；
- 画幅、时长、语言和编码符合要求；
- 所有视频均通过最终检查；
- 返工项已关闭或被明确记录；
- 交付表、文件夹和版本号一致；
- 外部发送、上传、填表和付费操作已获得当次授权。

## 4. 失败归因

不要把所有失败都归因于“模型随机”。建议区分：

- 需求歧义；
- 参考素材冲突；
- Prompt 没有绑定素材职责；
- 动作过载或时长不足；
- 产品/UI 事实缺失；
- 模型能力限制；
- 音频、口型或后期链路问题；
- 审核标准变化。

每次重试前先写清楚改变了哪个变量，否则重试只是重复消耗。
